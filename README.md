# shisaku — 起業ロードマップ秘書スキル for Claude Code

**思索（しさく）** は Claude Code 上で動く起業ロードマップ専門秘書エージェントです。確率論的起業メソッド（10回試行の確率論）と**深掘りラダー**を使い、新規ビジネスアイデアを「完全落とし込みの6要素」まで毎日壁打ちしながら1年で月商100万円を目指す1年ループを回します。

---

## 特徴

- **一問一答で終わらない** — 深掘りラダー（7層）で種から「最初の一手」まで掘り下げ
- **5つの問いパターン** — 不満起点・未来妄想・強制掛け合わせ・偏愛起点・既存ビジネス深掘り（ローテーション）
- **6要素で詰め切る** — 動機・ニッチ・ユーザー像・ペイン・新規性・最初の一手
- **Q1〜Q4ループ** — アイデア出し→絞り込み→開発→出口 を1年で一周
- **ClearDo連携はオプション** — タスク管理SaaSなしでも完全に動作します


### 2. 使い始める

Claude Code で:

```
/shisaku
```

または今日のアイデアを先渡しする場合:

```
/shisaku idea: 渋滞でも使える配達サービス
```

## 使い方

- `/shisaku` — セッション開始。秘書が前回メモを確認して今日の問いを出す
- `/shisaku idea: [メモ]` — アイデアを先渡しして深掘りから始める

セッションの流れ:
1. 秘書が問いを提示（A〜E のいずれかのパターン）
2. あなたが答える
3. 秘書が深掘りラダーに沿って次の層を掘る（1問で終わらない）
4. 6要素が揃ったら「完全落とし込み完了」
5. まとめを手元のメモに記録して次回への橋渡しで締め

---

## 深掘りラダー

```
種（アイデアの芽）
 └─ なぜそれが要るのか（動機・原体験）
     └─ 誰が一番困っているのか（人物を1人に絞る）
         └─ その人は今どう凌いでいるか（既存の代替手段）
             └─ なぜ既存手段ではダメなのか（不満の核）
                 └─ だったら何があれば解決するか（解の輪郭）
                     └─ なぜ"今"なのか・なぜ世に無かったのか（新規性）
                         └─ あなたが明日できる最初の一手は何か
```

## 四半期スケジュール

| 四半期 | 経過日数 | 目標 |
|---|---|---|
| Q1 | 0〜90日目 | アイデア出し → 深掘り → 10個に絞り込み |
| Q2 | 91〜180日目 | 10個を同時開発・リリース |
| Q3 | 181〜270日目 | 1点突破・プロへ投資 |
| Q4 | 271〜365日目 | 売却 / 拡大 / 複製 の選択 |

## オプション: ClearDo 連携

[ClearDo](https://cleardo.app) は Claude Code と MCP で繋がる **AI時代の目標管理 SaaS** です。Q1〜Q4 の目標ツリーをダッシュボードで可視化しながら、エージェントからセッション記録・進捗ログ・ToDo登録を直接実行できます。

> **ClearDo がなくてもスキルは完全に動作します。** 記録は手元のMarkdownファイルや Notion など好みのツールで代替できます。

MCP 連携を有効にすると:
- セッション開始時に過去ログを自動参照 → 同じ問いの繰り返しを防ぐ
- アイデア・判断・却下理由がタイムライン／フォーカスタブに蓄積
- 「最初の一手」が自動的に ToDo 登録されフォーカス管理に反映

有効化の手順は `.claude/agents/shisaku-secretary.md` の末尾「オプション: ClearDo 連携」節を参照してください。
