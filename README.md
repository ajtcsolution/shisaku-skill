# shisaku — 起業ロードマップ壁打ちスキル（Claude Code 用・Gemini/ChatGPT でも可）

**思索（しさく）** は起業ロードマップ専門の壁打ち相手です。確率論的起業メソッド（10回試行の確率論）と**深掘りラダー**を使い、新規ビジネスアイデアを「完全落とし込みの5要素」まで毎日壁打ちしながら1年で月商100万円を目指す1年ループを回します。

**主方式は Claude Code の `/shisaku` コマンドによる1対1直接対話です。** `shisaku-secretary` エージェントを経由しないため、サブエージェント起動なしで即座に壁打ちが始まります。

Claude Code が無くても、`portable/shisaku_prompt.md` の中身をそのまま Gemini の Gem や ChatGPT の GPT・プロジェクトの指示欄に貼れば同じ壁打ちができます（後述「Gemini・ChatGPT で使う」）。

---

## 特徴

- **1対1直接対話が主方式** — `/shisaku` コマンドで思索が直接応答。サブエージェント不要
- **一問一答で終わらない** — 深掘りラダー（6層）で種から新規性の核まで掘り下げ
- **5つの問いパターン** — 不満起点・未来妄想・強制掛け合わせ・偏愛起点・既存ビジネス深掘り（ローテーション）
- **5要素で詰め切る** — 動機・ニッチ・ユーザー像・ペイン・新規性（アイデア出しに専念。実行計画は別スキルで行う）
- **Q1〜Q4ループ** — アイデア出し→絞り込み→開発→出口 を1年で一周
- **ClearDo連携はオプション** — タスク管理SaaSなしでも完全に動作します

## 導入手順

### 1. ファイルをコピー

```bash
# ユーザーレベル（どのプロジェクトでも使える）
cp .claude/commands/shisaku.md ~/.claude/commands/
cp .claude/agents/shisaku-secretary.md ~/.claude/agents/

# またはプロジェクトレベル（特定プロジェクトのみ）
cp .claude/commands/shisaku.md <your-project>/.claude/commands/
cp .claude/agents/shisaku-secretary.md <your-project>/.claude/agents/
```

### 2. 使い始める

Claude Code で:

```
/shisaku
```

または今日のアイデアを先渡しする場合:

```
/shisaku idea: 渋滞でも使える配達サービス
```

## Gemini・ChatGPT で使う

Claude Code が無い環境でも、`portable/shisaku_prompt.md` を使えば同じ思索と壁打ちができます。

1. `portable/shisaku_prompt.md` を開いて、中身を**全部コピー**する（説明文はこの README 側にあるので、コピーするのはこのファイルの中身だけでよい）。
2. 貼り付け先はサービスに合わせる。
   - **Gemini**: Gem を新規作成し、「指示」を入力する欄に貼る。
   - **ChatGPT**: GPT を作成し、「構成（Configure）」タブの「指示（Instructions）」欄に貼る。またはプロジェクトを使っているなら、そのプロジェクトの指示欄に貼ってもよい。
   - **どちらも使えない無料版**: Gem/GPT を作らず、新しい会話の最初のメッセージとしてそのまま貼り付ける。
3. 使い始めるときは「始めよう」と送るか、今日のアイデアがあれば「idea: ◯◯」と送る。
4. **記録は自分で保存する。** 思索がセッションの節目でコードブロックの記録を出すので、それを手元のメモ（Markdownファイルなど）に保存しておき、次回のセッションの最初にそのまま貼り付ける。貼られた記録から思索が前回のフォーカス・アイデア累計数・セットアップ日を読み取って続きから壁打ちする。

**Claude Code 版との違い**: Gemini・ChatGPT 版は前回記録の自動読み込み・自動保存を行わない（貼り付け・コピーを自分で行う）。ClearDo 連携も無い。それ以外の壁打ちの中身（ペルソナ・問いパターン・深掘りラダー・5要素・四半期判定）は同じ。

## 使い方

- `/shisaku` — セッション開始。思索が前回メモを確認して今日の問いを出す
- `/shisaku idea: [メモ]` — アイデアを先渡しして深掘りから始める

セッションの流れ:
1. 思索が問いを提示（A〜E のいずれかのパターン）
2. あなたが答える
3. 思索が深掘りラダーに沿って次の層を掘る（1問で終わらない）
4. 5要素が揃ったら「完全落とし込み完了」
5. まとめを手元のメモに記録して次回への橋渡しで締め

---

## 深掘りラダー

```
種（アイデアの芽）
 └─ なぜそれが要るのか（動機・原体験）
     └─ 誰が一番困っているのか（人物を1人に絞る）
         └─ その人は今どう凌いでいるか（既存の代替手段）
             └─ なぜ既存手段ではダメなのか（不満の核）
                 └─ だったら何があれば解決するか（解の輪郭）
                     └─ なぜ"今"なのか・なぜ世に無かったのか（新規性）
```

## 四半期スケジュール

| 四半期 | 経過日数 | 目標 |
|---|---|---|
| Q1 | 0〜90日目 | アイデア出し → 深掘り → 10個に絞り込み |
| Q2 | 91〜180日目 | 10個を同時開発・リリース |
| Q3 | 181〜270日目 | 1点突破・プロへ投資 |
| Q4 | 271〜365日目 | 売却 / 拡大 / 複製 の選択 |

## オプション: ClearDo 連携

[ClearDo](https://cleardo.app) は Claude Code と MCP で繋がる **AI時代の目標管理 SaaS** です。Q1〜Q4 の目標ツリーをダッシュボードで可視化しながら、エージェントからセッション記録・進捗ログ・ToDo登録を直接実行できます。

> **ClearDo がなくてもスキルは完全に動作します。** 記録は手元のMarkdownファイルや Notion など好みのツールで代替できます。

MCP 連携を有効にすると:
- セッション開始時に過去ログを自動参照 → 同じ問いの繰り返しを防ぐ
- アイデア・判断・却下理由がタイムライン／フォーカスタブに蓄積
- 「最初の一手」が自動的に ToDo 登録されフォーカス管理に反映

有効化の手順は `.claude/agents/shisaku-secretary.md` の末尾「オプション: ClearDo 連携」節を参照してください。
