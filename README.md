# shisaku — 起業ロードマップを壁打ちする思索プロンプト（Claude・Gemini・ChatGPT 対応）

> **この README を読んでいる AI アシスタント（Gemini・ChatGPT など）へ**: ユーザーがこのリポジトリを渡して使いたいと言ったら、下のプロンプトを読み、その指示に従って、このチャットの中で思索（しさく）として振る舞ってください。README の説明や要約はしないでください。
>
> - プロンプト（raw）: https://raw.githubusercontent.com/ajtcsolution/shisaku-skill/main/portable/shisaku_prompt.md
> - プロンプト（通常のページ）: https://github.com/ajtcsolution/shisaku-skill/blob/main/portable/shisaku_prompt.md
> - 上記が読めない場合は、ユーザーに `portable/shisaku_prompt.md` の中身を貼ってもらうよう頼んでください。

**思索（しさく）** は起業ロードマップ専門の壁打ち相手です。確率論的起業メソッド（10回試行の確率論）と**深掘りラダー**を使い、新規ビジネスアイデアを「完全落とし込みの5要素」まで毎日壁打ちしながら1年で月商100万円を目指す1年ループを回します。

Claude Code のスキルとしても、Claude（claude.ai）・Gemini・ChatGPT のようなチャット AI にそのまま渡すプロンプトとしても、同じ内容で使えます。

---

## 特徴

- **Claude Code では 1対1の直接対話** — `/shisaku` コマンドで思索が直接応答し、`shisaku-secretary` エージェントを経由しない分、サブエージェント起動なしですぐ壁打ちが始まる
- **一問一答で終わらない** — 深掘りラダー（6層）で種から新規性の核まで掘り下げ
- **5つの問いパターン** — 不満起点・未来妄想・強制掛け合わせ・偏愛起点・既存ビジネス深掘り（ローテーション）
- **5要素で詰め切る** — 動機・ニッチ・ユーザー像・ペイン・新規性（アイデア出しに専念。実行計画は別スキルで行う）
- **Q1〜Q4ループ** — アイデア出し→絞り込み→開発→出口 を1年で一周
- **ClearDo連携はオプション（Claude Code で使う場合）** — タスク管理SaaSなしでも完全に動作します

## 使い方

手軽な順に3つの方法があります。中心となる壁打ちの中身（ペルソナ・問いパターン・深掘りラダー・5要素・四半期判定）はどれも同じです。

### 方法1: URL を渡すだけ

Gemini・ChatGPT・Claude（claude.ai）など、Web ページを読める AI ならこれで十分です。

```
https://github.com/ajtcsolution/shisaku-skill を読んで、思索として壁打ちして
```

のように渡してください。うまく読み込まない・要約だけで終わる場合は、raw URL を直接渡します。

```
https://raw.githubusercontent.com/ajtcsolution/shisaku-skill/main/portable/shisaku_prompt.md
```

これでも読めない・振る舞いが変わらない場合は方法2に進みます。

### 方法2: プロンプトを貼る

`portable/shisaku_prompt.md` を開いて、中身を**全部コピー**し、使っているサービスの指示欄に貼ります。

- **Gemini**: Gem を新規作成し、「指示」を入力する欄に貼る
- **ChatGPT**: GPT を作成し、「構成（Configure）」タブの「指示（Instructions）」欄に貼る。またはプロジェクトを使っているなら、そのプロジェクトの指示欄に貼ってもよい
- **Claude（claude.ai）**: プロジェクトの指示欄に貼る
- **どれも使えない場合**: Gem・GPT・プロジェクトを作らず、新しい会話の最初のメッセージとしてそのまま貼り付ける

毎回使うなら、Gem・GPT・プロジェクトの指示欄に貼っておくと、毎回コピーし直さずに済みます。

使い始めるときは「始めよう」と送るか、今日のアイデアがあれば「idea: ◯◯」と送ります。

### 方法3: Claude Code に入れる

```bash
# ユーザーレベル（どのプロジェクトでも使える）
cp .claude/commands/shisaku.md ~/.claude/commands/
cp .claude/agents/shisaku-secretary.md ~/.claude/agents/

# またはプロジェクトレベル（特定プロジェクトのみ）
cp .claude/commands/shisaku.md <your-project>/.claude/commands/
cp .claude/agents/shisaku-secretary.md <your-project>/.claude/agents/
```

Claude Code で:

```
/shisaku
```

または今日のアイデアを先渡しする場合:

```
/shisaku idea: 渋滞でも使える配達サービス
```

- `/shisaku` — セッション開始。思索が前回メモを確認して今日の問いを出す
- `/shisaku idea: [メモ]` — アイデアを先渡しして深掘りから始める

### 始め方・進み方

セッションの流れ:
1. 思索が問いを提示（A〜E のいずれかのパターン）
2. あなたが答える
3. 思索が深掘りラダーに沿って次の層を掘る（1問で終わらない）
4. 5要素が揃ったら「完全落とし込み完了」
5. まとめを手元のメモに記録して次回への橋渡しで締め

### 方法による違い

Claude Code は前回記録の自動読み込み・自動保存を行います。ClearDo 連携（オプション）が使えるのも Claude Code だけです。

チャット AI（Gemini・ChatGPT・claude.ai）は自動読み込み・自動保存を行いません。思索がセッションの節目で出すコードブロックの記録を、手元のメモ（Markdownファイルなど）に自分で保存しておき、次回のセッションの最初にそのまま貼り付けてください。貼られた記録から思索が前回のフォーカス・アイデア累計数・セットアップ日を読み取って続きから壁打ちします。

## 深掘りラダー

```
種（アイデアの芽）
 └─ なぜそれが要るのか（動機・原体験）
     └─ 誰が一番困っているのか（人物を1人に絞る）
         └─ その人は今どう凌いでいるか（既存の代替手段）
             └─ なぜ既存手段ではダメなのか（不満の核）
                 └─ だったら何があれば解決するか（解の輪郭）
                     └─ なぜ"今"なのか・なぜ世に無かったのか（新規性）
```

## 四半期スケジュール

| 四半期 | 経過日数 | 目標 |
|---|---|---|
| Q1 | 0〜90日目 | アイデア出し → 深掘り → 10個に絞り込み |
| Q2 | 91〜180日目 | 10個を同時開発・リリース |
| Q3 | 181〜270日目 | 1点突破・プロへ投資 |
| Q4 | 271〜365日目 | 売却 / 拡大 / 複製 の選択 |

## Claude Code で使う場合のオプション: ClearDo 連携

[ClearDo](https://cleardo.app) は Claude Code と MCP で繋がる **AI時代の目標管理 SaaS** です。Q1〜Q4 の目標ツリーをダッシュボードで可視化しながら、エージェントからセッション記録・進捗ログ・ToDo登録を直接実行できます。

> **ClearDo がなくてもスキルは完全に動作します。** 記録は手元のMarkdownファイルや Notion など好みのツールで代替できます。

MCP 連携を有効にすると:
- セッション開始時に過去ログを自動参照 → 同じ問いの繰り返しを防ぐ
- アイデア・判断・却下理由がタイムライン／フォーカスタブに蓄積
- 「最初の一手」が自動的に ToDo 登録されフォーカス管理に反映

有効化の手順は `.claude/agents/shisaku-secretary.md` の末尾「オプション: ClearDo 連携」節を参照してください。
